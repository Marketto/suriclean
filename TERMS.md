## 2. Che cosa fa l'app

SuriClean individua file e dati che potrebbero liberare spazio (cache, log, file temporanei, duplicati, file grandi, app poco usate, aree di sistema) e ti propone di spostarli nel Cestino, eliminarli, disinstallare app, cancellarne i dati o comprimere file con il motore di Schiaccia.

Le indicazioni dell'app («Sicuro», «Da controllare», «Con cautela», «Consigliati», le preselezioni, le stime dello spazio) sono valutazioni automatiche: possono essere sbagliate o non adatte al tuo caso.

Sei l'unico responsabile dei file e dei dati che selezioni e di ogni operazione che confermi, in particolare:

- eliminare file di sistema o di altri utenti, anche con la password di amministratore;
- disinstallare app o cancellarne i dati;
- comprimere file sostituendo gli originali (la compressione può ridurre la qualità).

Prima di confermare, controlla con attenzione cosa hai selezionato e tieni copie di sicurezza aggiornate dei dati importanti. Alcune operazioni non si possono annullare.
